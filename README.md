# Suite Conversores PowerShell (`conversores-ps`)

Herramientas portables para PowerShell en Windows 11:
- **`2md`**: Convierte PDF (digital o escaneado con OCR), DOCX, PPTX, XLSX, HTML, MSG, ZIP o archivos de código a Markdown (`.md`).
- **`2docx`**: Convierte `.md` a Word (`.docx`) con soporte de plantillas, `-Titulo`, `-Subtitulo` y `-SinTitulo`.
- **`2pdf`**: Convierte `.md` a PDF (`.pdf`) con soporte de plantillas, `-Titulo`, `-Subtitulo` y `-SinTitulo`.
- **`2code`**: Extrae bloques de código de un `.md` y crea los archivos físicos correspondientes.

## Instalación en 1 clic

1. Descarga el ZIP del repositorio (`Code -> Download ZIP`) y descomprímelo.
2. Haz doble clic en **`Instalar.bat`**.
3. Abre una nueva ventana de PowerShell y usa los comandos directamente.
